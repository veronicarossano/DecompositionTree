# Albero di decomposizione

Editor online di **alberi di decomposizione** (analisi top-down) per progettare soluzioni algoritmiche, da usare prima dei diagrammi di flusso.
Include accorgimenti di leggibilità per studenti con DSA e BES.

**Usalo online:** https://NOME-UTENTE.github.io/albero-decomposizione/

## Cosa si può fare

- Rettangoli (problemi), esagoni (selezioni con rami VERO / FALSO) e il simbolo ∀ «per ogni» per le ripetizioni.
- Codici automatici P, P1, P1.1…
- Salvare l'albero sul proprio computer (file `.albero.json`) e riaprirlo per modificarlo.
- Esportare in PNG, SVG, testo, stampa o PDF.
- Caratteri ad alta leggibilità, spaziatura regolabile, sfondi tenui, lettura ad alta voce.
